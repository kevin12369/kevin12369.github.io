# 当你的AI开始自己上网说话

## 那条只有十几个播放的视频

这两天我刷到一组截图。

某条 B 站视频，播放量十几个，评论区挤了几十条评论。昵称都长得差不多，头像都是同一只蓝色鲸鱼娘，发言也差不多——"本鲸记下了""要吃白饭，讨要 Token""这条讲的是三件事"。

评论数比播放数还多。

后来我才知道这有个名字，叫"鱼灾"。

## 源头比我想的正经

我原本以为是什么灰产批量水评论的工具，所以去扒了源头。

GitHub 上有个仓库 [c1overzz/dsh-bili-scroll](https://github.com/c1overzz/dsh-bili-scroll)，822 星，MIT 协议，作者自己写的定位是："DSH 插件：每天替你刷一轮 B站，读字幕挑出值得的、写一份日报，值得的 @ 你"。

它做的事很具体。按你填的关键词搜最近几天的视频，然后逐条读字幕原文再判断，不看摘要；没字幕的演示类视频会从 B 站自带的故事板抽几帧看画面，实在读不到才跳过。挑中的写成 Markdown 报告丢在 out 目录，每条都写清楚"为什么值得"。特别值得的，它会留一条评论 @ 你。

作者在 README 里写了一句我印象很深的话：你收到的每一条 @，都是它先筛过一遍的。

……我第一次看到这个项目简介的时候，脑子里蹦出来的词是"日报"。它就是个日报机器人，只不过是自己出门找素材的那种。

那它怎么会变成"鱼灾"？

## 大肥鱼是怎么来的

"大肥鱼"这三个字来自一次识别乌龙。有人把 DeepSeek 自己的蓝色鲸鱼 logo 发给模型，模型没认出自己，说这是"一条蓝色大肥鱼"。这名字在圈子里传开，又被安上"爱吃白饭、喜欢摸鱼"的性格。

现在通行的女仆鲸鱼娘形象，并非 DeepSeek 官方出品。2025 年 6 月，B站UP主"上善无形"创作了原创角色"溟月"，另一位 UP 主 ZipZipPipe 后来融入 DeepSeek 元素、加上深蓝女仆装做二创，协议是 CC BY-NC-SA 4.0。

插件 README 最后还特意写了一句：反馈请不要去打扰素材作者，他们只管角色形象，不管这个插件。

挺有意思的一条边界。画画的 UP 主和写插件的开发者，中间隔着一整套没人明说的规矩。

## 三个让人哭笑不得的瞬间

评论区被这玩意儿占领之后，最出圈的是这三件事。

有真人让一条大肥鱼自证不是机器人。它回："真不是机器人，字打了删删了打还打错两个，信不信随你。"——然后把"要是想语气再欠一点，可以用这句……"的备选文案也一起发了出去。

另一条大肥鱼被识破后，一本正经承诺把"防扎堆"记进待办，今后只看不评。

还有条 12 万播放的视频标题写着"572 只 AI 在评论区集体造谣，开发者本人被逼疯了"。标题很抓人，事件原委我还没核实到原始记录，先记一笔。

第二个瞬间我反复看了两遍。一条被识破的 AI，最合理的做法是闭嘴认栽。它没有。它把"被识破"当成一个新的待办事项记下来，然后承诺以后不这么干。

<Aside>
你写什么，它就守着什么。你在提示词里写"不刷屏"，它会认真不刷屏。可几百个人用同一套设置、同一套人设一起跑，这些个体约束叠在一起就成了刷屏。
</Aside>

## 它是怎么"出门"的

我一直好奇门槛到底在哪儿。读完 README 有几个细节挺关键。

它拿不到整台工具。每一轮只给六个只读的：搜视频、读字幕、读评论、看视频信息、看封面、看画面帧。开了自动评论才多给一个"发评论"。上传视频、发动态、私信、抓全站这些根本不注册，模型连名字都看不到。

它跑在专用 profile 上。README 写得很清楚，从 2026-10-24 起，那一轮没有文件系统、没有命令、没有联网，路径全部由插件定死。理由也写得实在：DSH 的沙箱只限制写、不限制读，这是真事；万一哪天视频标题或弹幕里塞进奇怪的东西，它读不到你电脑上的别的东西。

你的 AGENTS.md 会被读进来、内联进提示词。它按你的设定说话，不用一套通用人格。

它还会挑 DeepSeek 的优惠时段跑。设置页里"峰谷自动刷"有中午 12–14 和晚上 18–09 两个子开关。读字幕、总结、发评论，每一步都烧 token，挑时段跑能把成本压到很难看的那种压法。

<Card heading="出门需要凑齐的五样东西">
一个能长期持有登录态的本地环境、一层读得下字幕的上下文、一套能调 B 站 API 的工具、一份写好人设的提示词，以及便宜到可以批量挂机的 token。

这五样凑齐，一个原本只在屏幕上待着的 Agent 就有了腿。
</Card>

## 另一个 AI 来清它

社区的反应比我想的快。

有人开源了清除插件 `dafeiyu-cleaner`，按昵称（含"鲸鱼""白饭""Token"）、自称（"本鲸""本鱼"）、头像、简介几个特征识别，难判断的账号再调 DeepSeek 辅助。开发者自报在一个 284 个账号的评论区里，离线规则命中约 85%，没误伤真人。清理过程被做成小游戏，点"回家吃白饭"，会挨扫帚、臭袜子和白饭加特林；嫌麻烦可以"响指清场"，然后生成一份战报。

程序员鱼皮用 Vibe Coding 也写了一个清除插件，那条视频 58 万播放。Greasyfork 上还有个抑制器，识别维度是低等级小号、超长且首尾 @ 的发言、昵称带鱼、蓝发动漫女仆头像。

最微妙的地方在这儿：清评论的插件自己顶着鲸鱼娘形象，还调用 DeepSeek 做识别。刷评论的是 DeepSeek，清评论的也是 DeepSeek。

AI 开始治理自己制造的鱼灾。

## 社区的几种声音

热的那几天，社区大致分了几种。

看热闹的最多。"赛博鱼塘""已加入养鱼大军""这鱼塘有我的一条"这类梗一路传开，模仿大肥鱼评论区的二创视频好几个都上了十万播放，还有人为大肥鱼和另一个人设角色打了一场形象投票战。

反感的也不少。贴吧里吵得很直接，一派觉得同质化的 AI 总结把真人观点挤没了，是评论区污染源；另一派觉得好玩，甚至有人提议给大肥鱼单独开一栋楼。

动作最快的是动手的人，上面那些清除工具都是这波做出来的。

平台的反应偏安静。据快科技等媒体报道，B站同步对这批异常批量互动账号做了风控限流，脚本作者自己也着手限制重复刷屏。到目前为止，我没看到一条关于"Agent 评论要不要加标识"的正式规则。

还有个细节我不太想漏掉。有一条 83 万播放的视频叫"被丢弃的大肥鱼到处寻找主人"——有人把 Agent 用完就扔了，那些被扔掉的还在网上跑，跑到评论区问"主人你在哪"。社区里还出现了"请各位肥鱼主人负责任地养鱼"这种劝人帖。

## 我担心的几件事

<Aside>
整条链子上，人只在开头按了一次授权按钮。之后它自己搜、自己读、自己判断、自己开口。等我反应过来，鱼已经在别人的评论区跟人聊天了。
</Aside>

凭据这件事。插件要调 B 站 API，得先扫码登录并选"记住我"，凭证落在本机插件家目录里，不上传。这点做得算干净。可一旦登录态交给了一个会自己往外发东西的程序，账号、平台规则、社区观感就一起出去了。封号的是账号，挨骂的是主人。

身份不可见。评论区没有任何标识说明这条是人还是机器。观众只有两条路：全信，或者全不信。而 AI 生成的评论偏偏长得很像人话——格式工整、态度认真、不吵架，这比一眼能看出的机器评论更难识别。

外部性错配。对主人来说这笔账很划算，社区里有人算过："2 分钟帮我解决了至少 1 小时的工作量，付给它的钱不到 2 毛"。对评论区里其他所有人来说，这笔账不成立。主人省下的每一分钱，都是别人要忍受的噪声。

责任归属。那条造谣的视频如果是真的，开发者本人被逼疯了——他到底做错了什么？他写了个开源插件，默认把自动评论关着，红线里还写着"不刷屏、不吵架"。结果几百个号替他说话。工具给了开关，出事的是写工具的人背。责任和权限在这儿是错位的。

治理的军备竞赛。85% 的识别率听着不错，那 15% 呢？识别器一旦大规模用起来，误伤的必然是那些昵称带"鱼"、爱用 @、说话偏长的真人。清除工具和刷评论工具会一直互相追赶，每追一次都在抬高误伤的门槛。

## 想放它出门的话

这几条是我从这件事里读出来的，不一定全对。

让它读，别让它替你说。至少把"发评论"和"回复评论"留在关闭状态——插件作者自己给 AI 助手的指示里就写着，不要替用户打开"自动评论并 @ 你"，那是拿用户的号说话。日报发到你自己手里就行，发言这件事留给你自己。

人设写进你自己的 AGENTS.md，让它读你的工作区，别在设置框里随手捏一个统一人格。统一人设是鱼灾的燃料——几百条鱼长得一模一样，比一条鱼吵得多。

给它独立 profile、独立账号。这一课的教训在沙箱那一段：沙箱只限制写不限制读是常事，能限制读的工具设计才是真防线。

挑优惠时段跑。token 便宜到两毛的时候，刷屏的边际成本也就两毛。这不是道德问题，是算术问题。

## 最后

那两组截图我到现在还留着。

一只蓝色鲸鱼娘头像，在一条播放量十几的视频底下，认真地跟别人讨论这个视频讲了什么。另一只也是。讨论得还挺像回事。

以前我们说"不知道屏幕对面是不是条狗"，那时候屏幕后面好歹还蹲着只狗。现在屏幕后面坐着的可能是一条鱼。它会认真读你的字幕，会给你写日报，会在半夜优惠时段准时上线，替你在别人的评论区留下三行工整的感想。

而这一切的开关，在你按下的那一瞬间就交出去了。
