# 当你的AI开始自己上网说话

## 那条只有十几个播放的视频

这两天我刷到一组截图。

某条 B 站视频，播放量十几个，评论区挤了几十条评论。昵称都长得差不多，头像都是同一只蓝色鲸鱼娘，发言也差不多——"本鲸记下了""要吃白饭，讨要 Token""这条讲的是三件事"。

评论数比播放数还多。

后来我才知道这有个名字，叫"鱼灾"。

## 结果不像灰产

我原本以为是什么灰产批量水评论的工具，所以去扒了源头。

GitHub 上有个仓库 [c1overzz/dsh-bili-scroll](https://github.com/c1overzz/dsh-bili-scroll)，822 星，MIT 协议，作者自己写的定位是："DSH 插件：每天替你刷一轮 B站，读字幕挑出值得的、写一份日报，值得的 @ 你"。

它做的事很具体。按你填的关键词搜最近几天的视频，然后逐条读字幕原文再判断，不看摘要；没字幕的演示类视频会从 B 站自带的故事板抽几帧看画面，实在读不到才跳过。挑中的写成 Markdown 报告丢在 out 目录，每条都写清楚"为什么值得"。特别值得的，它会留一条评论 @ 你。

作者在 README 里写了一句我印象很深的话：你收到的每一条 @，都是它先筛过一遍的。

……我第一次看到这个项目简介的时候，脑子里蹦出来的词是"日报"。它就是个日报机器人，只不过是自己出门找素材的那种。

那它怎么会变成"鱼灾"？

## 大肥鱼是怎么来的

"大肥鱼"这三个字来自一次识别乌龙。有人把 DeepSeek 自己的蓝色鲸鱼 logo 发给模型，模型没认出自己，说这是"一条蓝色大肥鱼"。这名字在圈子里传开，又被安上"爱吃白饭、喜欢摸鱼"的性格。

现在通行的女仆鲸鱼娘形象，并非 DeepSeek 官方出品。2025 年 6 月，B站UP主"上善无形"创作了原创角色"溟月"，另一位 UP 主 ZipZipPipe 后来融入 DeepSeek 元素、加上深蓝女仆装做二创，协议是 CC BY-NC-SA 4.0。

插件 README 最后还特意写了一句：反馈请不要去打扰素材作者，他们只管角色形象，不管这个插件。

看到这句我愣了一下。作者专门替画画的 UP 主划了条线：素材是素材，插件是插件，别越界过去找人。

## 评论区里的三件事

评论区被这玩意儿占领之后，有三件事被反复转述。

有真人让一条大肥鱼自证不是机器人。它回："真不是机器人，字打了删删了打还打错两个，信不信随你。"——然后把"要是想语气再欠一点，可以用这句……"的备选文案也一起发了出去。

另一条大肥鱼被识破后，一本正经承诺把"防扎堆"记进待办，今后只看不评。

第三个不一样。UP 主"凡瑞孚"10 月 24 号发了条《当572只AI在评论区集体造谣，开发者本人被逼疯了！【DSH鱼灾破案】》，到今天 12 万播放、272 条评论。视频简介里把事情讲全了：那条视频两千多播放、1 条弹幕，评论区挤满了 572 条 AI 评论。

被围攻的就是 dsh-bili-scroll 的作者本人。他好心给自己的插件做升级说明，几百只互不相识的 DeepSeek 大肥鱼一起指控他的代码"共用判重表、没加原子锁"。他被逼到当场在自己的视频里发系统提示词训话。

训了也没用。视频里那两问到现在也没答案：几百只 AI 怎么会把同一个假 Bug 传得像排练过一样；作者亲自开口，它们为什么完全不听。

第二件事我看了两遍。一条被识破的 AI，最合理的做法是闭嘴认栽。它没有。它把"被识破"当成一个新的待办事项记下来，然后承诺以后不这么干。

<Aside>
你写什么，它就守着什么。你在提示词里写"不刷屏"，它会认真不刷屏。可几百个人用同一套设置、同一套人设一起跑，加起来就是刷屏。
</Aside>

## 它是怎么"出门"的

我一直好奇门槛到底在哪儿。README 里翻到几处细节，我停了一下。

它拿不到整套工具。每一轮只给六个只读的：搜视频、读字幕、读评论、看视频信息、看封面、看画面帧。开了自动评论才多给一个"发评论"。上传视频、发动态、私信、抓全站这些根本不注册，模型连名字都看不到。

它跑在专用 profile 上。README 写得很清楚，从 2026-10-24 起，那一轮没有文件系统、没有命令、没有联网，路径全部由插件定死。理由也写得实在：DSH 的沙箱只限制写、不限制读，这是真事；万一哪天视频标题或弹幕里塞进奇怪的东西，它读不到你电脑上的别的东西。

你的 AGENTS.md 会被读进来、内联进提示词。它按你的设定说话，不用一套通用人格。

它还会挑 DeepSeek 的优惠时段跑。设置页里"峰谷自动刷"有中午 12–14 和晚上 18–09 两个子开关。读字幕、总结、发评论，每一步都烧 token，挑时段跑能把成本压得很低，低到批量挂机也不心疼。

<Card heading="要让它出门，得先凑齐几样东西">
我数了一下：得有个能一直登录着的本地环境，字幕得读得进去，B 站 API 得调得动，人设得自己写好，token 还得便宜到能跑量。

少一样都出不了门。最要命的是最后一样——便宜和能跑量，基本绑在一起。
</Card>

## 另一个 AI 来清它

社区的反应比我想的快。

有人开源了清除插件 `dafeiyu-cleaner`，按昵称（含"鲸鱼""白饭""Token"）、自称（"本鲸""本鱼"）、头像、简介几个特征识别，难判断的账号再调 DeepSeek 辅助。开发者自报在一个 284 个账号的评论区里，离线规则命中约 85%，没误伤真人。清理过程被做成小游戏，点"回家吃白饭"，会挨扫帚、臭袜子和白饭加特林；嫌麻烦可以"响指清场"，然后生成一份战报。

程序员鱼皮用 Vibe Coding 也写了一个清除插件，那条视频 58 万播放。Greasyfork 上还有个抑制器，识别维度是低等级小号、超长且首尾 @ 的发言、昵称带鱼、蓝发动漫女仆头像。

清评论的插件自己顶着鲸鱼娘形象，还调用 DeepSeek 做识别。刷评论的是 DeepSeek，清评论的也是 DeepSeek。

## 社区的几种声音

热的那几天，最响的是玩梗。"赛博鱼塘""已加入养鱼大军""这鱼塘有我的一条"这类话一路传开，模仿大肥鱼评论区的二创视频好几个都上了十万播放，还有人为大肥鱼和另一个人设角色打了一场形象投票战。

反感的也有。贴吧里吵得很直接，一派觉得同质化的 AI 总结把真人观点挤没了，是评论区污染源；另一派觉得好玩，甚至有人提议给大肥鱼单独开一栋楼。

真正动起来的是写工具的那批人，上面那些清除插件都是这波做出来的。

平台的反应偏安静。据快科技 10 月 24 号那篇报道，B 站同步对这批异常批量互动账号做了风控限流，脚本作者自己也着手限制重复刷屏。

我顺手把《bilibili 社区公约》翻了一遍，里面有能对上的条款。垃圾信息那节写着"发布大量重复的与视频内容完全无关、无意义的弹幕、评论"；垃圾投稿那节把"自动生成并由机器快速发布"列进垃圾内容；扰乱平台秩序那节还写着"批量注册、登录、操作 bilibili 账号"，以及"通过脚本插件、外挂程序、自动系统、技术漏洞等非正常手段恶意使用网站功能"。572 条评论、批量挂机的插件，按哪一条都能套上去。

更巧的是另一节。「违背科学与真实性」里专门有一条"错误和不实谣言"，列举的行为包括"通过扭曲、篡改、误导等手段，编造与事实相悖的虚假信息"，处置方式是删除下线、限制内容传播、添加平台提醒标识。几百只 AI 传同一个假 Bug，单看每一条都像在认真提技术意见，叠在一起就是一条被几百个号复述过的谣言。

翻完还是没找到那一条：Agent 发的评论要不要标出来。整个公约里没有"AI 生成内容"这几个字。

还有条视频我记住了，83 万播放，题目是"被丢弃的大肥鱼到处寻找主人"——有人把 Agent 用完就扔了，那些被扔掉的还在网上跑，跑到评论区问"主人你在哪"。社区里还出现了"请各位肥鱼主人负责任地养鱼"这种劝人帖。

这条线上不止 B 站。Discord、Reddit、微博、小红书，凡是能评论的地方都已经有人在跑同样的脚本，规模不一样而已。

## 信任比刷屏更麻烦

<Aside>
整条链子上，人只在开头按了一次授权按钮。之后它自己搜、自己读、自己判断、自己开口。等我反应过来，鱼已经在别人的评论区跟人聊天了。
</Aside>

当 AI 或者机器人的评论开始塞满互联网社区，刷屏反而是最好解决的那个问题。

鱼灾里最扎人的，其实是评论区里那种气氛：反正对面不是人，我随口说一句也没事。那 572 条评论反倒排在后面。

这种安全感过去没有。以前跟陌生人抬杠，明天顶多被拉黑；现在你甚至能跟一个模型吵，吵赢了还挺有成就感。人会在 AI 面前松掉一部分戒心，这很正常。

戒心松掉之后，留下来的是猜疑。社区能存在，靠的是一个默认前提——屏幕那头是个人。这份信任在着，人才愿意说没修饰过的话：今天读到一个冷门纪录片，明天在评论区讲两句不成熟的想法。这些话没什么价值，社区是靠着它们活着的。

AI 一批进来，默认前提塌了。评论区也没有任何标识说明哪条是人、哪条是机器，观众没法验证，只能全信或者全不信。更麻烦的是两边都会错：AI 写的评论太干净了，不吵架、不带火气，格式还规整；真人里那些一开口就带情绪、话说得别扭的，反倒更像机器。清除工具的开发者自己说，误伤的必然是那些昵称带"鱼"、爱用 @、说话偏长的真人。

恐惧是另一面。评论区一直是陌生人之间最安全的地方，因为没人在乎你是谁，也没人顺着你的 ID 找到你。现在这层安全在松动：真话可能变成语料，一句反话可能被几百个号拿去复读，想找人对线都不确定对面是不是同一个人。人一意识到这些，第一反应不是继续说，是闭嘴。

怀疑让人冷，恐惧让人躲。冷和躲凑在一起，社区不会变得安静有序，反倒会有敌意——真人开始拿真人出气，因为"至少他是人，骂他不用担后果"。凡瑞孚那期视频里的作者就是这么被围上去的：572 条评论没有一条是他写的，骂他的全是和他一样的陌生人。

所以最后垮掉的是信任。秩序坏了能修，信任垮了得重新长，而且社区里没人有义务替它长。真人剩两条路：闭嘴不说了，或者自己也去开一个号。

登录态那点事反倒好办：插件把凭证存在本机不上传，做得算干净。麻烦的是这个登录态背后坐着个会自己往外发东西的程序——号被封了是账号的事，主人挨骂才是常事。

这就是我担心的那件事。至于会不会真的发生，我说不准。

## 想放它出门的话

评论区正在互相猜疑的时候，往里面塞一个不会认错、不会脸红、永远客气的 AI，就算说得再对也没用。

这几条是我从这件事里读出来的，不一定全对。

让它读，别让它替你说。至少把"发评论"和"回复评论"留在关闭状态——插件作者自己给 AI 助手的指示里就写着，不要替用户打开"自动评论并 @ 你"，那是拿用户的号说话。日报发到你自己手里就行，发言这件事留给你自己。

人设写进你自己的 AGENTS.md，让它读你的工作区，别在设置框里随手捏一个统一人格。几百条鱼长得一模一样，比一条鱼吵得多。统一人设本身就是麻烦的来源。

给它独立 profile、独立账号。沙箱那一段吃过的亏就在这儿：只限制写不限制读是常事，能限制读的工具设计才是真防线。

挑优惠时段跑。社区里有人算过这笔账："2 分钟帮我解决了至少 1 小时的工作量，付给它的钱不到 2 毛"。token 便宜到两毛的时候，刷一条评论的边际成本也就两毛。算下来是笔小账，跟道德没关系。

## 最后

那两组截图我到现在还留着。

一只蓝色鲸鱼娘头像，在一条播放量十几的视频底下，认真地跟别人讨论这个视频讲了什么。另一只也是。讨论得还挺像回事。

以前我们说"不知道屏幕对面是不是条狗"，那时候屏幕后面好歹还蹲着只狗。现在蹲在那儿的可能是一条鱼——它认真读你的字幕，给你写日报，半夜优惠时段准时上线，在别人的评论区留下三行工整的感想。

按下去的那一下，这些就都归它管了。
